# Work board

The list of what is planned for this repository, in the order to do it, so any session (with the owner there or not) can find the next task without asking. It is the roadmap's Phase 1 and the start of
Phase 2 ([document 11](11-roadmap.md)) made into one table; the work list for the first application is in [document 12](12-mortgage-first.md). The rules for working from it are in [CLAUDE.md](../CLAUDE.md) and
[Ways of working](14-ways-of-working.md).

Ask the board what is next:

```text
python tools/board.py next               # the task in progress, else the first ready one
python tools/board.py next --unattended  # the same, but only tasks marked auto
python tools/board.py check              # is the board itself valid?
python tools/board.py list               # every task with its status
```

`tools/test_board.py` runs `check` in the Python test step of CI, so a board that loses an id, loops, or marks a task done with no commit fails the build.

**Status** is `todo`, `doing` (at most one), `blocked` (Result says why) or `done` (Result is the commit). **Who** is `auto` (safe to do while the owner is away: local, reversible, covered by tests),
`ask` (a choice between designs, a public contract, a new dependency, a CI change, or anything the owner will see: do it with the owner) or `owner` (only the owner can). **Depends** lists ids that must be done first.
