# Repository map

Every project and top-level folder, with the first sentence of its own README. Generated by `python tools/doc_checks/run.py map`:
do not edit by hand; change the folder's README and run the script. A test fails when this file is out of date.

## The packages

| Folder                      | What it is                                                                                                                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/Backplane.Conventions` | The conventions tests as a package (roadmap task 1.3): rules that read an application's C# with Roslyn, and its client's TypeScript as text, and fail the build when a written standard is broken. |
| `src/Backplane.Sdk`         | The build rules every application starts with, as an MSBuild SDK package.                                                                                                                          |

## The tests

| Folder                              | What it is                                                                                                      |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `tests/Backplane.Conventions.Tests` | Proves each rule in `Backplane.Conventions` on samples, and holds this repository's own code to the same rules. |
| `tests/Backplane.Sdk.Tests`         | Proves `Backplane.Sdk` by using it.                                                                             |

## Operations and documentation

| Folder    | What it is                                                                                                                                                                                                                                                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `docs`    | The rulebook: strategy, principles, architecture, quality gates, testing, validation and errors, logging, security, capability modules, repositories and delivery, the documentation standard, the roadmap, the work list for the first application, the ways of working and the UI and UX standards, numbered in the order to read them. |
| `scripts` | Scripts you run on your own machine: today, `check.ps1`, which runs this repository's checks one command per tier.                                                                                                                                                                                                                        |
| `tools`   | Small scripts that check this repository's own documents.                                                                                                                                                                                                                                                                                 |
